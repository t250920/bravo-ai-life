③ 결과물 읽기

승인 판정: 조건부 보류. 두 번째 클립에 로고가 생겼다면 브랜드 로고 사용 금지 조건에 위배된다. 해당 클립은 로고가 없는 안전 구간만 사용하거나 C 접점으로 전면 대체한다.

순서·소스인~아웃길이대체컷
1 C 전체0~5초5초정지
2 A 정상0~2.5초2.5초C 접점
3 C 접점0~6초6초정지
4 B 정상0~3.5초3.5초C 확인
5 C 확인0~3초3초정지
합계20초

수정 지시: 2번에 로고가 보이면 전체 2.5초를 C 접점으로 교체한다. 로고를 단순히 가려 홈이나 받침을 훼손해서는 안 된다.

최종 승인 조건은 홈 3개, 제품 외형 일치, 흔들림 오류 제외, 로고·얼굴 없음, 총 20초다.
