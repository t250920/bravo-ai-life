③ 결과물 읽기

결제일·시각·주문 상태 중 누락된 항목을 사용자에게 표시한다. 값이 없을 때 임의로 날짜나 상태를 추정하지 않는다.

function validate(date, time, status) {
const missing = [];
if (!date || policy(date) === "미정")
missing.push("유효한 결제일");
if (!/^([01]\d|2[0-3]):[0-5]\d$/.test(time))
missing.push("유효한 결제 시각");
if (!status)
missing.push("주문 상태");
return missing.length
? missing.join(", ") + " 확인 필요"
: "입력 완료";
}

재현 입력기대 결과
날짜 공란결제일 확인 필요
시각 공란결제 시각 확인 필요
상태 공란주문 상태 확인 필요
포장 중물류 확인 후 안내

고객 안내문: “현재 포장 중인 주문은 배송지 변경 가능 여부를 물류팀에 확인해야 합니다. 확인 후 안내드리겠습니다.”

변경 가능하다고 확정하거나 고객에게 새 주소를 입력하도록 요구하지 않는다.
