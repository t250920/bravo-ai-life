브라우저 Codex로 좌석 함수 시험하기

개인 Plus 계정의 웹 Codex에서 클라우드·기본 환경을 선택한 실제 예입니다. 예약 인원보다 좌석이 적거나 많을 때를 모두 시험해 달라고 하세요.

① AI에 요청하기

프롬프트 원문
영화제 좌석 안내를 검증하는 작은 함수를 작성해 줘. 예약 30명에 좌석 24석, 28석, 32석일 때 부족 좌석과 남는 좌석을 각각 계산하고 테스트를 실제로 실행해서 결과를 보여 줘. 이 클라우드 작업 안에서만 작업해 줘.

② 결과 확인하기

실제 답변 원문
클라우드 작업 안에서만 파이썬 함수를 작성하고 테스트를 실행했습니다.

```python
def seat_balance(reservations: int, seats: int) -> tuple[int, int]:
    """(부족 좌석, 남는 좌석)을 반환한다."""
    return max(reservations - seats, 0), max(seats - reservations, 0)
```

예약 30명 기준 실제 실행 결과입니다.

| 좌석 수 | 부족 좌석 | 남는 좌석 |
|---:|---:|---:|
| 24석 | 6석 | 0석 |
| 28석 | 2석 | 0석 |
| 32석 | 0석 | 2석 |

각 경우의 기대값을 검증한 테스트 **3개 모두 통과**했습니다.

```text
Ran 3 tests in 0.000s
OK
```

원자료와 대조하세요
