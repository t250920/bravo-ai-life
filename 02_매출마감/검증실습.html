01

Excel에서 발견한 오류를 AI에 전달해요

수량을 4개에서 5개로 바꾸자 집계값은 9,800원 늘었지만 독립 검산값이 달랐습니다. 오류 셀, 현재값, 기대값과 보존할 원자료를 지정해 수정 요청을 보냅니다.

실제로 보낸 후속 프롬프트
Windows Excel 전체 재계산(Ctrl+Alt+F9)에서 독립 검산식 오류를 확인했어. 원본 사본의 F1992를 4→5로 바꾸면 집계 10월 순매출은 90,871,800으로 정상 증가하지만 검산 B10은 92,222,500, C10은 90,871,800이야. B8도 2,948,400으로 반품 합계 4,640,500과 달라. 배열 INDEX/MATCH를 SUMPRODUCT 안에서 쓰는 독립식이 Excel에서 제대로 계산되지 않는 것으로 보여. 검산 시트 오른쪽에 반품 272행의 독립 보조 계산표를 만들어, 각 행에서 원본_반품을 참조하고 원본_주문의 단가·귀속월·상태를 단일 VLOOKUP 또는 INDEX/MATCH로 찾고 마감 승인·완료 조건의 차감액을 IF로 구해 줘. B8·B9·B10은 이 보조표와 원본 주문에서 독립 계산하고 집계 시트를 참조하지 않게 해. 원본 값은 원래대로(원본_주문 F1992=4) 보존해. 기준 합계는 8월 92535800, 9월 97999600, 10월 90862000, 총 반품 4640500이야. 고정값으로 맞추지 마. 날짜 서식과 숫자 캐시 문제도 해결한 bravo_sales_checked.xlsx를 만들어 줘. 원자료 변경에 따라 실제로 계산될 수식을 넣고 수정된 셀과 검산 결과를 설명해 줘.

AI가 수정한 파일과 계산 경로를 확인해요

AI 최종 수정 Excel 받기

검산 시트의 G:O열은 원본 반품 272건을 직접 참조합니다. 각 반품의 단가·귀속월·주문상태를 찾아 반품차감액을 계산합니다. AI가 보고한 검산값과 Windows Excel에서 직접 재계산한 결과를 구분하세요.

검산!O2 · 승인·마감일·완료 조건
=IF(AND(K2="승인",I2<=DATE(2026,10,31),N2="완료"),J2*L2,0)
검산!B8 · 반품 합계
=SUM(O2:O273)
검산!B10 · 10월 독립 순매출
=SUMPRODUCT((원본_주문!C2:C3001="2026-10")*(원본_주문!H2:H3001="완료")*원본_주문!F2:F3001*원본_주문!G2:G3001)-SUMIF(M2:M273,"2026-10",O2:O273)

열계산 내용
G:K원본_반품의 번호·주문번호·날짜·수량·상태 직접 참조
L원본_주문에서 실판매단가 조회
M원본_주문에서 귀속월 조회
N원본_주문에서 주문상태 조회
O승인·마감일·완료 조건에 따른 반품차감액

검산!L2 — 단가 조회

excel
=IF(AND(K2="승인",I2<=DATE(2026,10,31),N2="완료"),J2*L2,0)

두 수식을 포함한 보조표 수식은 273행까지 적용했습니다.

검산!B8 — 전체 반품차감액

excel

검산!B9 — 전체 순매출

excel
=B7-B8

검산!B10 — 10월 독립 순매출

excel
=SUMPRODUCT(
(원본_주문!C2:C3001="2026-10")*
(원본_주문!H2:H3001="완료")*
원본_주문!F2:F3001*
원본_주문!G2:G3001
)-SUMIF(M2:M273,"2026-10",O2:O273)

B8·B9·B10은 월별집계나 계산_주문 시트에 의존하지 않습니다.

수량을 바꾼 뒤 원상 복원해요

파일을 열어 Ctrl+Alt+F9로 전체 재계산합니다. 검산 시트의 차이 D열이 모두 0인지 확인합니다.

이름 상자에 원본_주문!F1992를 입력하고 Enter를 누릅니다. 수량을 5로 바꾼 뒤 검산 시트에서 B10과 C10이 모두 90,871,800원인지 확인합니다. 단가 9,800원만큼 늘어야 합니다.

F1992를 다시 4로 되돌립니다. B10과 C10이 90,862,000원으로 복원되고 차이는 0이어야 합니다. 복원 후 저장하세요.

검산 결과 확인

수량을 4개에서 5개로 바꾸면 두 계산 경로 모두 9,800원 증가하고 차이는 0원입니다. 주문 추가 시 3,001행까지인 수식 범위를 넓히도록 AI에 다시 요청합니다.
