① 열 이름을 주고 수식을 받아 보세요

학생용 원본의 사본에서 진행합니다. 새 ChatGPT 대화에 아래 요청을 넣으세요. 이 실습은 열 설명으로 수식을 만드는 작업입니다.

입력 프롬프트
주문대장의 F열은 수량, G열은 단가, H열은 상태, I열은 승인반품수량이야. 취소 매출은 0원이야. 판매금액 J2, 차감액 K2, 순매출 L2에 넣을 Excel 수식을 주소와 함께 3줄만 줘.

② 답변에서 수식만 복사하세요

학생용 사본의 주문대장 J2, K2, L2에 아래 수식을 하나씩 붙여넣으세요. 취소일 때 금액을 어떻게 처리했는지 IF 안에서 확인하세요.

J2 · 판매금액
=IF(H2="취소",0,F2*G2)
K2 · 반품차감액
=IF(H2="취소",0,I2*G2)
L2 · 순매출
=J2-K2
내가 확인할 것

J2와 L2는 10,500원, K2는 0원입니다.
